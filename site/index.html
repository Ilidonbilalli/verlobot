What we catch

The eight leaks that quietly burn turns, points, and customers.

🔇

Silent turns

The model thinks, spends the budget, and returns nothing. The run stalls; nobody notices.

🔄

Stuck loops

The same command re-run again and again, expecting a different result.

💥

Error storms

Failing retry loops that never change strategy, burning minutes and dollars.

🏆

False success claims

"All tests pass" — when the last run says 3 failed. The run ends on a lie.

🪓

Weakened tests

skip / xfail / assert True added to make things "pass". Fake greens, hidden reds.

✂️

Truncated output

Half-written files and unbalanced fences — the fix breaks the build.

💬

Prose instead of action

"Let me check the tests..." and no tool call. A turn that produces nothing.

🌧️

Context floods

One 200k-char log dump buries the task; everything after it is garbage.

🩺

And the fix

Every leak has a known, cheap repair. We implement them and show before/after numbers.

FAQ

Is my data safe?

The free tool runs entirely in your browser — nothing is uploaded, nothing is stored. For paid work we sign an NDA on request and only ask for the logs you choose to share, with a deletion window that we confirm in writing.

What log formats do you support?

JSONL (one JSON object per line), JSON arrays, and raw text logs. OpenAI, Anthropic, LangChain, Claude Code, custom agent frameworks — the parser is tolerant, and if a format is exotic we can adapt quickly.

How fast do I get results?

Free autopsy: instant. First watchtower report: within 7 days of connecting your logs. Alerts: minutes.

What if you find nothing?

Month one is credited if the first report finds nothing actionable. If your logs are clean, we say so, in writing.

How do I cancel?

Monthly: anytime. Yearly: stop the renewal at any time; access continues to the end of the paid term.

Who are you?

A small team that builds verification and evaluation tooling for agent systems. We keep our promise: find real failures, fix them, prove the numbers.

Can you work with our stack?

If your agent emits logs, yes. We stay out of your way: read-only review, minimal integration, everything changes behind a reviewable pull request.
