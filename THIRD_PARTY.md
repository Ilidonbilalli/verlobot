## Rules for future contributions

- Only original code, or permissive licenses (MIT / Apache-2.0 / BSD) with
  attribution added to this file.
- Never paste code from GPL/AGPL sources into this repository.
- Never add images, fonts, music, or logos from third parties unless we can
  point to a clear license or receipt (see `docs/legal-rules.md`).
